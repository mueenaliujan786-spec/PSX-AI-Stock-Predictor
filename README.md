# 📈 PSX AI Stock Price Predictor

A supervised learning project in Python. The main part predicts Pakistan Stock Exchange (PSX) stock prices with Linear Regression and shows the results in a Streamlit web app. Four extra parts cover classification, neural networks, image recognition and financial news sentiment analysis.

> **Disclaimer:** This is an educational project. It is not financial advice.

## Live App
```bash
streamlit run app.py
```

## Screenshots
![Dashboard](screenshots/dashboard.png)

## Project Parts
| Part | Technique | Dataset / Task |
|------|-----------|----------------|
| 1 | Linear Regression | PSX stock price prediction |
| 2 | Logistic Regression + KNN | Wine classification |
| 3 | ANN (Neural Network) | Iris dataset |
| 4 | ANN vs CNN | Fashion-MNIST |
| 5 | NLP Sentiment Analysis | Financial news |

## Results
| Model | Result |
|-------|--------|
| Linear Regression (PSX) | R² = 0.85 |
| Logistic Regression (Wine) | 100% accuracy |
| ANN (Iris) | 100% accuracy |
| CNN (Fashion-MNIST) | 91.63% accuracy |

## Tech Stack
Python, Streamlit, scikit-learn, TensorFlow, yfinance, pandas, NumPy, Matplotlib
