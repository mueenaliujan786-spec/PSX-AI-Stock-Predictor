# 📈 PSX AI Stock Price Predictor

AI Lab Project — Supervised Learning

## Project Overview
A complete supervised learning project covering 5 techniques: regression, classification, neural networks, image recognition, and NLP.

## Parts
- Part 1 — Linear Regression (PSX Stock Prediction)
- Part 2 — Logistic Regression + KNN (Wine Classification)
- Part 3 — ANN Neural Network (Iris Dataset)
- Part 4 — ANN vs CNN (Fashion-MNIST)
- Part 5 — NLP Sentiment Analysis (Financial News)

## Live App
Run with: `streamlit run app.py`

## Technologies
Python, Streamlit, scikit-learn, TensorFlow, yfinance, pandas, numpy, matplotlib

## Results
- Linear Regression R² = 0.85
- Logistic Regression = 100% accuracy
- ANN Iris = 100% accuracy
- CNN Fashion-MNIST = 91.63% accuracy
